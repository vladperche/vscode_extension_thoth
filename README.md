# Thoth
Thoth is a VSCode Extension to save and share HTTP Requests as a text files, so, they can be versioned in any Git repositories.

## Requisites

1. **Node & npm**: Required to build the extension TypeScript files
2. **VS Code**: Built-in Extension Host debugger

## Run and Test

1. Open the `${workspaceFolder}` in **VS Code**
2. Press `F5` (or click **Run --> Start Debugging**)
3. **VS Code** will automatically compile TypeScript and open a sandbox window running the **Thoth** extension where you can open `*.thoth` files
